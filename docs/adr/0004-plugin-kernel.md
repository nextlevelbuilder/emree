# ADR 0004: Plugin-first, trusted kernel

Status: proposed baseline; D04,D13.

Composable official modules, data-only third-party extensions, typed services/events and deterministic cleanup inspired by DSH. Alternative in-process arbitrary plugin code rejected for enterprise trust boundary. Core auth, policy, credentials, consent, stop and updater cannot be overridden. Signed catalog, version/digest and permissions, lifecycle with rollback, scoped context and resource owner. F05/A06 demonstrate active/disabled/failure and refusal. Sandbox custom executable UI deferred until isolation proven; revoke package or disable slot without affecting core chat.
