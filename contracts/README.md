# Contract drafts

The current JSON Schema and CRM example are design fixtures, not an executable SDK. Validate the manifest and separately enforce package signatures, digest, compatibility, unique namespaced contribution IDs, exact allowed paths, policy and permission checks. A schema-valid manifest grants no capability. Future joint Dewee review produces canonical OpenAPI/JSON Schema fixtures for bootstrap, rooms/events, session tickets and broker commands. See [API/data contracts](../docs/CONTRACTS.md) and [extension spec](../docs/EXTENSIONS.md).
